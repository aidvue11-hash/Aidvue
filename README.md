
# Aidvue (split install)
1) Unzip **core-v13.zip** into a folder (e.g., `aidvue`).
2) Unzip **ext-a-v13.zip**, **ext-b-v13.zip**, **ext-c-v13.zip** into the **same folder** and choose “Merge/Replace” if asked.
3) Unzip **infra-v13.zip** last into the **same folder**.
4) Upload the combined folder to Netlify (Deploy manually).

Optional: Replace `/public/assets/hero.mp4` and `.webm` with your 5‑second loop before deploy.
